
# ระบบจองนิมนต์พระ วัดโพธิ์แจ้ (Wat Phojae Booking System)

เว็บไซต์สำหรับประชาสัมพันธ์และระบบจองนิมนต์พระออนไลน์ของวัดโพธิ์แจ้ จ.สมุทรสาคร

## 🚀 การใช้งานบน GitHub Pages (Demo Mode)
หากท่านเข้าชมเว็บไซต์นี้ผ่าน GitHub Pages โปรดทราบว่า:
- **ระบบทำงานในหมวด "สาธิต (Demo)"**: เนื่องจาก GitHub Pages รองรับเฉพาะหน้าเว็บนิ่ง (Static Site) ไม่สามารถรันระบบหลังบ้าน (Backend Python) ได้
- **ข้อมูลถูกบันทึกในเครื่องของท่าน**: การจองต่างๆ จะถูกบันทึกไว้ในเบราว์เซอร์ของท่านเท่านั้น (LocalStorage) ไม่ถูกส่งไปยังเซิร์ฟเวอร์จริง
- **ฟีเจอร์ที่ปิดใช้งาน**: การแจ้งเตือน LINE, การบันทึกลง Google Sheets และการซิงค์ข้อมูลระหว่างเครื่อง

## 💻 การติดตั้งและใช้งานจริง (Local Installation)
หากต้องการใช้งานระบบเต็มรูปแบบ (Full Feature) ต้องรันบนคอมพิวเตอร์ที่มี Python

### 1. ติดตั้งโปรแกรมที่จำเป็น
- ติดตั้ง [Python](https://www.python.org/downloads/) (ตอนติดตั้งให้ติ๊กถูกช่อง "Add Python to PATH")
- ติดตั้ง [Git](https://git-scm.com/downloads)

### 2. ติดตั้ง Dependencies
รันไฟล์:
```
install_deps.bat
```
หรือพิมพ์คำสั่ง:
```bash
pip install -r requirements.txt
```

### 3. ตั้งค่าการเชื่อมต่อ (Optional)
สร้างไฟล์ `.env` โดยดูตัวอย่างจาก `env_template.txt` เพื่อตั้งค่า:
- `LINE_NOTIFY_TOKEN`: สำหรับการแจ้งเตือนไลน์
- `GOOGLE_CREDENTIALS_JSON`: สำหรับเชื่อมต่อ Google Sheets

### 4. รันเซิร์ฟเวอร์
รันไฟล์:
```
run_server.bat
```
เมื่อเซิร์ฟเวอร์ทำงาน จะสามารถเข้าใช้งานได้ที่: `http://localhost:5000`

## 📁 โครงสร้างโปรเจกต์
- `index.html`: หน้าหลักเว็บไซต์และแบบฟอร์มจอง
- `admin.html`: หน้าจัดการสำหรับเจ้าหน้าที่
- `app.py`: ระบบหลังบ้าน (Backend Server)
- `script.js`: ควบคุมการทำงานหน้าเว็บ
- `style.css`: รูปแบบและการตกแต่ง
